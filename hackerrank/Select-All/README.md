# SQL Challenge — Select All

SQL exercise solved on **HackerRank**.

## 🎯 Challenge Description

Query **all columns (attributes)** for every row in the `CITY` table.

The goal is to retrieve all available data from the table without applying any filtering conditions.

## 💡 Solution

```sql
SELECT *
FROM CITY;
```

## 📚 Concepts Practiced

* `SELECT` statement
* `SELECT *`
* `FROM` clause
* Querying all columns
* Retrieving all rows from a table

## 🧠 What I Learned

This challenge demonstrates the basic structure of a SQL query.

Using `SELECT *` tells SQL to return **all columns** from the specified table.

Because there is no `WHERE` clause, the query returns **every row** contained in the `CITY` table.

This is one of the simplest SQL queries, but it is fundamental for understanding how data is retrieved from relational databases.
